Batch

API Batch = kuyruk. Gönderdikten sonra bilgisayarını kapatabilirsin — iş Google sunucularında biter (genelde 24 saat içinde, çoğu zaman daha hızlı). Sonuçlar 6 hafta saklanır. Geri geldiğinde aşağıdan Durum veya İndir demen yeterli. Sürekli istek atmana gerek yok.

Yerel: parçaları hemen paralel üretir (sekme açık kalmalı). API Batch: kuyruğa atar, %50 daha ucuz. Ayırıcı boşsa paragraflara bölünür.
